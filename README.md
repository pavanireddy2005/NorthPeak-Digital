# 🌞 NorthPeak Digital

A modern, responsive one-page digital agency website built as part of the **Digital Heroes Web Development Qualification Task**.

The website showcases a fictional digital agency named **NorthPeak Digital** and follows the **Graphical Sunshine** theme with a clean, modern UI, smooth animations, responsive layout, and Dark/Light mode support.

---

## 📌 Features

- Responsive One-Page Website
- Modern Graphical Sunshine Theme
- Light & Dark Mode Toggle
- Sticky Navigation Bar
- Hero Section
- About / Why Choose Us Section
- Services Section
- Client Testimonials
- Pricing Plans
- Contact Form
- Interactive Footer
- Scroll-to-Top Button
- Smooth Scrolling Navigation
- Mobile-Friendly Design
- Hover Animations & Transitions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
- Google Fonts

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click **index.html**
   OR
4. Open it using **Live Server** in Visual Studio Code.

No additional installation is required.
